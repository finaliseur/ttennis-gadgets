#**=== TTENNIS-GADGETS ===**

L'outil pour tous les pongistes !
Disponible sur toutes les plateformes.

#**version : v1.0.0.**

TTENNIS GADGETS est votre ami à vous tous amis pongistes.

L'application est pour l'instant découpé en 2 sections.

1 - Un calculateur de points


Rentrez votre classement actuel.
Remplissez un tableau avec les match faits.
(Classement de l'adversaire, victoire ou défaite).


Voyez le gain s'afficher.
Une phrase bilan qui calcule pour vous, votre classement après la dérive en fonction des matchs joués.

2 - Statistiques

Choississez un partenaire d'entraînement ou un rivale.
Rentrer vos matchs (en 3, 5 ou peut importe le nombre de sets).

Des statistiques rien que pour vous.  
- Moyenne du nombre de set gagné (entre 0 et 1)
- Moyenne du nombre de set perdu (entre 0 et 1)
- Fréquence de victoire
- Fréquence de défaite
- Un graphique montrant le rapport victoire / défaite.
